## Prompt 1 — Guia de estudo da unidade

```
Crie um guia de estudo da Unidade 8 (Projeto Final). Organize em:
- Objetivos de aprendizagem (5)
- Escopo do projeto (o que entregar, 4 entregáveis)
- Os 3 prompts obrigatórios (quais frameworks usar)
- Cronograma de 2 semanas (4 etapas, 8h)
- Rúbrica de correção (5 critérios × 4 níveis) + conversão de nota
- Apresentação oral (5 min, composição 80/20)
- 3 casos sugeridos
- 5 erros comuns a evitar
```

---

## Prompt 2 — Quiz de 10 questões

```
Gere 10 questões de múltipla escolha (4 alternativas) sobre o projeto final:
- 2 sobre escopo e entregáveis
- 2 sobre os 3 prompts obrigatórios (2 frameworks diferentes + 1 avançado)
- 2 sobre a rúbrica de correção (5 critérios)
- 2 sobre conversão de nota e aprovação
- 2 sobre pegadinhas (ex.: "é esperado usar IA", "copiar de colega é falta grave")
Marque a resposta correta e justifique em 1 linha.
```

---

## Prompt 3 — Flashcards

```
Gere 12 flashcards "Frente: pergunta / Verso: resposta (máx 15 palavras)":
- 3 cards: 4 entregáveis (descrição, 3 prompts, rúbrica, reflexão)
- 2 cards: 3 prompts obrigatórios (2 práticos + 1 avançado)
- 2 cards: rúbrica de correção (5 critérios, conversão de nota)
- 2 cards: apresentação oral (5 min, 80/20)
- 2 cards: erros comuns a evitar
- 1 card: aprovação (nota ≥ 7,0)
```

## Prompt 4 — Podcast (Audio Overview) da unidade

```
Crie um diálogo de podcast (2 apresentadores, ~10 min) sobre o projeto final.
Estrutura:
1. Parabéns por chegar até aqui — projeto final é a síntese do curso
2. O que entregar: 4 entregáveis (descrição, 3 prompts, rúbrica, reflexão)
3. Os 3 prompts obrigatórios: 2 frameworks práticos + 1 avançado (ReAct ou BDI)
4. Cronograma de 2 semanas, 8 horas
5. A rúbrica de correção: 5 critérios, compartilhada ANTES da entrega
6. Apresentação oral: 5 minutos, composição 80/20
7. É esperado usar LLMs — o que se avalia é a construção do prompt
8. 3 casos sugeridos para quem não tem caso próprio
Tom motivacional. Termine com: "Mão na massa. Vejo vocês na defesa."
```

## Prompt 5 — Escolha guiada de caso

```
Vou descrever minha situação profissional. Sugira 3 casos possíveis para
o projeto final, considerando:
- Que envolvam pelo menos 1 tarefa que se beneficia de IA
- Que permitam usar 2 frameworks práticos diferentes
- Que permitam usar ReAct ou BDI no terceiro prompt
Para cada caso, indique: qual framework usar em cada prompt, por quê.
Situação: [descreva sua situação aqui]
```

---

## Prompt 6 — Planejamento do projeto

```
Vou descrever o caso que escolhi para o projeto final. Monte um plano
detalhado em 4 etapas (semana 1 + semana 2), indicando para cada etapa:
- Atividade específica
- Horas estimadas
- Entregável do dia
- Critério de "pronto" objetivo
Caso: [descreva seu caso aqui]
```

---

## Prompt 7 — Simulação de defesa oral

```
Aja como instrutor do curso. Eu vou descrever meu projeto final (caso,
3 prompts, frameworks usados). Faça-me as 5 perguntas mais prováveis
que um avaliador faria na defesa oral (Aula 12), uma por uma, esperando
minha resposta antes de passar à próxima. Ao final, dê feedback
estruturado usando os 5 critérios da rúbrica do projeto-final.
Projeto: [descreva seu projeto aqui]
```

---

## Prompt 8 — Autoavaliação com a rúbrica do projeto

```
[Após concluir e colar seu projeto final] Avalie seu próprio projeto
usando a rúbrica de correção (5 critérios × 4 níveis). Para cada
critério, dê nota de 1 a 4 e justifique. Calcule a nota bruta e converta
para escala 0-10. Identifique o critério mais fraco e sugira 1 melhoria
antes de entregar.
```

---

## Prompt 9 — FAQ da unidade

```
Gere um FAQ com 10 perguntas que um aluno faria sobre o projeto final:
- "Preciso usar os 3 frameworks diferentes?"
- "Posso usar qualquer LLM?"
- "É permitido usar IA para gerar as saídas?"
- "A apresentação oral é obrigatória?"
- "O que acontece se eu copiar de colega?"
- "Como é calculada a nota final?"
- "E se eu não tiver um caso próprio?"
- "A rúbrica é compartilhada antes da entrega?"
- "Quanto tempo tenho?"
- "E se eu não passar?"
Respostas em até 3 linhas.
```

## Prompt 10 — Síntese para revisão final do curso

```
Resuma o curso inteiro em uma única página A4 organizada em:
- Título: "Prompt Engineering na Prática — Revisão Final"
- Tabela dos 5 frameworks/técnicas (RACE, TAG, CARE, ReAct, BDI) com:
  componentes, quando usar, nível de evidência
- Caixa "Rúbricas: ponte entre frameworks e avaliação"
- Tabela "Para o projeto final: 3 prompts, 2 frameworks, 1 rúbrica"
- Checklist final "Antes de entregar: ..."
- Mapa de aprendizagem contínua: links para OpenAI, Anthropic, DAIR.AI,
  Learn Prompting
Formato pronto para imprimir como PDF de revisão final.
```

## Prompt 12 — Mensagem motivacional final

```
Escreva uma mensagem motivacional de encerramento do curso (150 palavras)
que o instrutor pode enviar aos alunos após a defesa do projeto final.
Inclua: parabéns por completar, lembrete das competências conquistadas,
```
