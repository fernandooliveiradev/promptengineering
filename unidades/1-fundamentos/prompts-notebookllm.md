# Unidade 1 — Promontos para NotebookLM

> Cole estes prompts diretamente no NotebookLM após carregar como fontes:
> - `docs/prompt-engineering.md`
> - `unidades/1-fundamentos/conteudo.md`
> - `exercicios.md` (exercícios 1.1 a 1.5)

---

## Prompt 1 — Guia de estudo da unidade

```
Crie um guia de estudo para a Unidade 1 (Fundamentos do Prompt Engineering).
Organize em 3 seções (Aula 1.1, 1.2, 1.3). Para cada uma, liste:
- 1 objetivo de aprendizagem
- 3 conceitos-chave com definição de 1 linha cada
- 1 ponto que mais cai em avaliação
- 1 dica prática
Inclua ao final "3 erros comuns do iniciante em prompt engineering".
```

---

## Prompt 2 — Quiz de 10 questões

```
Gere 10 questões de múltipla escolha (4 alternativas cada) cobrindo a Unidade 1:
- 3 sobre definição de prompt engineering e arte vs ciência
- 3 sobre as 5 seções de um prompt profissional
- 4 sobre as 6 técnicas (zero-shot, few-shot, CoT, role, structured, chaining)
Marque a resposta correta e justifique em 1 linha citando a seção do arquivo.
```

---

## Prompt 3 — Flashcards

```
Gere 12 flashcards no formato "Frente: pergunta / Verso: resposta de até 15 palavras".
Cubra:
- Definição de prompt engineering (2 cards)
- As 5 seções do prompt (5 cards, um por seção)
- 5 técnicas estabelecidas (5 cards, uma por técnica)
Use linguagem direta, sem jargão.
```

---

## Prompt 4 — Podcast (Audio Overview) da unidade

```
Crie um diálogo em formato de podcast (2 apresentadores, ~7 min) cobrindo:
1. O que é prompt engineering e por que é arte + ciência
2. A regra de ouro (mostre a um colega sem contexto)
3. As 5 seções de um prompt profissional, com o exemplo do revisor de texto
4. A diferença entre zero-shot e few-shot
5. Por que chain-of-thought resolve o problema das "5 máquinas, 5 peças"
Tom didático e descontraído. Termine com um convite para a Unidade 2 (RACE).
```

---

## Prompt 5 — Explicação para leigo

```
Explique o que é prompt engineering para alguém que nunca ouviu falar,
em 200 palavras, usando uma analogia do cotidiano (não use "receita de bolo").
Em seguida, explique em 100 palavras adicionais a diferença entre um prompt
vago e um prompt específico, usando o exemplo "fale sobre ia" vs a versão
reformulada. Mantenha tom acessível, sem jargão.
```

## Prompt 6 — FAQ da unidade

```
Gere um FAQ com 8 perguntas que um aluno iniciante faria na Unidade 1.
Cubra: "prompt é código?", "qual LLM usar?", "preciso programar?",
"o que é few-shot?", "CoT é só para matemática?", "exemplo serve
para tudo?", "tem prompt perfeito?", "como sei que deu certo?".
Resposta objetiva em até 3 linhas cada.
```

## Prompt 7 — Mapa mental textual

```
Gere um mapa mental em outline (indentado) da Unidade 1.
Raiz: "Fundamentos do Prompt Engineering".
Nível 1: as 3 aulas.
Nível 2: conceitos de cada aula.
Nível 3: 1 exemplo representativo por conceito.

```

## Prompt 8 — Crítica de prompt do aluno

```
[Após colar um prompt que você escreveu] Avalie este prompt identificando:
1. Quais das 5 seções (Identidade, Instruções, Exemplos, Contexto, Entrada)
   estão presentes e quais faltam
2. Quais das 6 técnicas (zero-shot, few-shot, CoT, role, structured, chaining)
   ele usa, ainda que implicitamente
3. 3 sugestões concretas de melhoria baseadas nas boas práticas da unidade
Formato: tabela para o item 1 e 2, lista para o item 3.
```

---

## Prompt 9 — Perguntas-guia (flipped classroom)

```
Gere 3 perguntas abertas que o aluno deve responder ANTES de assistir
a cada uma das 3 aulas da Unidade 1. Pergunta provocativa, não factual
— algo que ele só conseguirá responder bem depois de ver a aula.
Formato: "Antes da Aula 1.X, reflita: ..."
```

## Prompt 10 — Síntese para revisão

```
Resuma a Unidade 1 em uma única página, organizada em:
- 1 parágrafo de abertura (o que é prompt engineering)
- 1 tabela das 5 seções do prompt
- 1 tabela das 6 técnicas
- 1 caixa de destaque com a regra de ouro
- 1 checklist final "Antes de enviar seu prompt: ..."
Formato pronto para imprimir como PDF de revisão.
```

## Dica de uso

Carregue **apenas** os 3 arquivos listados no topo — não carregue os 11 arquivos do curso inteiro de uma vez. NotebookLM prioriza fontes; com muitas fontes, ele dilui o foco da unidade.
