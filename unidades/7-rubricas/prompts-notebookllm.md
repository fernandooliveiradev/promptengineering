## Prompt 1 — Guia de estudo da unidade

```
Crie um guia de estudo da Unidade 7 (Rúbricas). Organize em:
- Definição (1 linha, com citação de Popham 1997)
- Componentes (critérios, descritores, níveis)
- 3 tipos (holística, analítica, de desenvolvimento) com quando usar
- Benefícios para professor e aluno (3 cada)
- Método de 5 passos (Goodrich 1996)
- Por que rúbricas importam para prompt engineering
- 2 dicas práticas
- Aviso: rúbricas para prompt engineering são construção didática
```

## Prompt 2 — Quiz de 12 questões

```
Gere 12 questões de múltipla escolha (4 alternativas) sobre rúbricas:
- 2 sobre definição e componentes
- 2 sobre os 3 tipos (holística, analítica, de desenvolvimento)
- 2 sobre o método de 5 passos de Goodrich
- 2 sobre benefícios (professor e aluno)
- 2 sobre rúbricas para prompt engineering (RACE, saída de IA)
- 2 sobre pegadinhas (ex.: "consistência = validade?", "quantos critérios?")
Marque a resposta correta e justifique em 1 linha.
```

```
Gere 15 flashcards "Frente: pergunta / Verso: resposta (máx 15 palavras)":

- 2 cards: quando usar / quando não usar
```

## Prompt 5 — Construção guiada de rúbrica analítica

```
Vou descrever uma tarefa a ser avaliada. Construa uma rúbrica analítica
(4 critérios × 4 níveis: Iniciante, Em desenvolvimento, Proficiente,
Avançado). Para cada célula, escreva um descritor observável e específico.
Para cada critério, justifique brevemente por que o escolheu (1 linha).
Tarefa: [descreva a tarefa aqui]
```

---

## Prompt 6 — Crítica de rúbrica

```
[Após colar uma rúbrica que você construiu] Avalie esta rúbrica verificando:
1. Tem 3-7 critérios (nem pouco nem muito)?
2. Os descritores são observáveis (não inferencia)?
3. Os descritores diferenciam claramente os níveis (não são repetições)?
4. Há alinhamento entre critérios e objetivos de aprendizagem?
5. Faltaria algum critério importante? Sobra algum?
Formato: tabela + 3 sugestões de melhoria.
```

---

## Prompt 7 — Avaliação de saída de IA com rúbrica

```
[Após colar uma saída de IA que você quer avaliar] Use a rúbrica-exemplo
de saída de IA (seção 2.11 do conteudo.md, com 5 critérios: precisão
factual, aderência, clareza, formatação, tom) para avaliar esta saída.
Para cada critério, dê nota de 1 a 4 e justifique citando trecho da
resposta. Calcule a nota final (média) e converta para escala 0-10.
```

## Prompt 8 — Avaliação de prompt RACE com rúbrica

```
[Após colar um prompt RACE que você escreveu] Use a rúbrica-exemplo
para prompts RACE (seção 2.10 do conteudo.md, com 4 critérios: Role,
Action, Context, Expectation) para avaliar este prompt. Para cada
critério, dê nota de 1 a 4 e justifique citando trecho do prompt. Dê
3 sugestões concretas de melhoria.
```
