# Rúbrica — Guia Conceitual e Prático

> Documentação de apoio para cursos online.
> Material didático sobre o conceito de **rúbrica** (rubric), sua tipologia, construção, aplicação e uso no contexto de IA generativa.

---

## 1. Definição

Uma **rúbrica** (do inglês *rubric*) é um **instrumento de avaliação** que descreve, de forma explícita, as expectativas de desempenho do instrutor para uma tarefa ou trabalho. Em termos simples, é um **conjunto de critérios para classificar atribuições**.

> *"A rubric is a scoring guide used to evaluate the quality of students' constructed responses."* — James Popham (1997)

Tipicamente apresentada em formato tabular, uma rúbrica contém:

- **critérios** (*criteria*): os aspectos de desempenho que serão avaliados;
- **descritores** (*descriptors*): as características associadas a cada nível de cada critério;
- **níveis de desempenho** (*performance levels*): uma escala de avaliação que identifica o grau de domínio do estudante em cada critério.

Ela cumpre **papel duplo**:

1. **Para o professor/orientador:** guia a correção, tornando-a mais consistente e rápida.
2. **Para o aluno:** explicita expectativas e padrões, permitindo autoavaliação e direcionamento de esforço.

---

## 2. Componentes de uma rúbrica

Segundo Herman, Aschbacher e Winters (1992), uma rúbrica de avaliação típica inclui:

| Componente | Descrição |
|---|---|
| **Traços/dimensões** | Os critérios que servem de base para julgar a resposta. |
| **Definições e exemplos** | Esclarecem cada traço/dimensão. |
| **Escala de valores** | Graduação para classificar cada dimensão (ex.: Insuficiente, Regular, Bom, Excelente). |
| **Padrões de excelência** | Modelos ou exemplos que ilustram níveis específicos de desempenho. |

## 3. Tipos de rúbrica

A literatura reconhece três tipos principais:

### 3.1 Rúbrica Holística (*Holistic Rubric*)
Fornece **uma única nota global** para o trabalho inteiro, considerando todos os aspectos em conjunto.

| Quando usar | Vantagem | Limitação |
|---|---|---|
| Avaliações rápidas, visão geral, feedback sumário | Rapidez, simplicidade | Feedback pouco específico — aluno não sabe quais dimensões melhorar |

### 3.2 Rúbrica Analítica (*Analytic Rubric*)
Avalia **cada dimensão ou componente separadamente**, com critérios e descritores próprios para cada um.

| Quando usar | Vantagem | Limitação |
|---|---|---|
| Feedback detalhado, identificar pontos fortes/fracos por dimensão | Diagnóstico preciso, feedback acionável | Mais demorada para construir e aplicar |

### 3.3 Rúbrica de Desenvolvimento (*Developmental Rubric*)
Subtipo da rúbrica analítica que utiliza **múltiplas dimensões de sucessões de desenvolvimento** para apoiar avaliação, design instrucional e **aprendizagem transformacional**. Define "modos de prática" dentro de uma comunidade de especialistas e indica aprendizagem transformacional pela mudança dinâmica entre níveis.

> **Modos típicos:** *beginning, exploring, sustaining, inspiring* (iniciante, explorador, mantenedor, inspirador). O **timing** dos quatro níveis é único em cada dimensão — é comum conviverem modos iniciantes em uma dimensão com modos avançados em outra.

**Propriedades das rúbricas de desenvolvimento:**
1. São descrições de exemplos de comportamentos.
2. Contêm múltiplas dimensões, cada uma com poucos modos de prática mutuamente exclusivos.
3. Os modos de prática dentro de uma dimensão mostram sucessão dinâmica de níveis.
4. Podem ser criadas para escalas de tempo/lugar extremamente diversas.

## 4. Benefícios comprovados

### 4.1 Para instrutores
- **Reduz o tempo de correção** — o instrutor referencia uma descrição substantiva em vez de escrever comentários longos.
- **Identifica tendências da turma** — pontos fortes e fracos recorrentes ficam visíveis, permitindo ajustar o ensino.
- **Garante consistência** — entre diferentes momentos e entre diferentes avaliadores.
- **Reduz incerteza** na correção.
- **Inibe contestações** de notas — os critérios são explícitos.

### 4.2 Para estudantes
- **Compreende expectativas e padrões** do instrutor.
- **Usa feedback para melhorar** o desempenho.
- **Autoavalia e monitora** seu progresso rumo a metas claras.
- **Reconhece pontos fortes e fracos** e direciona esforços.

## 5. Como criar uma rúbrica — método em 5 passos

Método clássico de Goodrich (1996):

| Passo | Ação | Detalhe |
|---|---|---|
| **1** | **Model Review (Revisão de modelos)** | Apresente aos alunos exemplos de trabalhos de qualidade variada para análise. |
| **2** | **Criteria Listing (Listagem de critérios)** | Liste colaborativamente os critérios da rúbrica, incorporando feedback dos alunos. |
| **3** | **Quality Gradations (Graduações de qualidade)** | Defina categorias hierárquicas que descrevam níveis de qualidade ou desenvolvimento. |
| **4** | **Practice on Models (Prática em modelos)** | Permita que os alunos apliquem a rúbrica a trabalhos-exemplo, para aprofundar a compreensão. |
| **5** | **Self and Peer Assessment (Auto e heteroavaliação)** | Introduza autoavaliação e avaliação por pares para reforçar a aprendizagem. |

### 5.1 Roteiro operacional para o instrutor

```
1. Defina os objetivos de aprendizagem da tarefa.
2. Liste 3-7 critérios (dimensões) que importam para o sucesso da tarefa.
3. Para cada critério, escreva descritores claros para cada nível da escala.
4. Defina a escala (ex.: 4 níveis — Iniciante, Em desenvolvimento, Proficiente, Avançado).
5. Atribua pesos se algumas dimensões forem mais importantes que outras.
6. Teste a rúbrica em trabalhos-exemplo e refine os descritores ambíguos.
7. Compartilhe a rúbrica com os alunos ANTES da entrega do trabalho.
```

## 6. Quando usar rúbricas

| Situação | Adequação |
|---|---|
| Avaliações individuais (redações, projetos, apresentações) | ✅ Adequado |
| Projetos de capítulo/capstone | ✅ Adequado |
| Múltiplos avaliadores corrigindo a mesma tarefa | ✅ Muito adequado — garante consistência |
| Avaliação de componentes de um projeto | ✅ Adequado — fornece critérios por componente |
| Tarefas objetivas de múltipla escolha | ❌ Desnecessário — gabarito basta |
| Avaliações de resposta única correta | ❌ Desnecessário |

## 7. Anatomia visual de uma rúbrica analítica

Uma rúbrica analítica é tipicamente uma **matriz**:

```
                   | Nível 1        | Nível 2        | Nível 3        | Nível 4
                   | (Iniciante)    | (Em desen-     | (Proficiente)  | (Avançado)
                   |                | volvimento)   |                |
-------------------|----------------|----------------|----------------|-----------
Critério A         | descritor A1   | descritor A2   | descritor A3   | descritor A4
(ex.: Clareza)     |                |                |                |
-------------------|----------------|----------------|----------------|-----------
Critério B         | descritor B1   | descritor B2   | descritor B3   | descritor B4
(ex.: Argumento)   |                |                |                |
-------------------|----------------|----------------|----------------|-----------
Critério C         | descritor C1   | descritor C2   | descritor C3   | descritor C4
(ex.: Evidência)   |                |                |                |
```

Cada célula contém um **descritor** — frase que descreve o que o trabalho apresenta naquele nível daquele critério. Descritores devem ser:
- **Observáveis** (não inferencia).
- **Específicos** (não vagos).
- **Diferenciados** entre níveis (não repetições disfarçadas).
- **Compartilhados** com os alunos antes da entrega.

## 8. Rúbricas no contexto de IA generativa

### 8.1 Por que rúbricas importam para prompt engineering?

Rúbricas são **a ponte entre os frameworks de prompt (RACE, TAG, CARE) e a avaliação objetiva de resultados**. Sem rúbrica, julgar se um prompt é "bom" fica subjetivo. Com rúbrica, transforma-se a avaliação em **processo replicável, auditável e ensinável** — essencial em cursos online.

### 8.2 Três usos típicos em cursos de IA

| Uso | O que avalia | Exemplo de critério |
|---|---|---|
| **Avaliar prompts dos alunos** | Se o prompt segue um framework | "Presença de Role explícita e específica" (RACE) |
| **Avaliar saídas da IA** | Qualidade da resposta gerada | "Precisão factual: sem alucinações verificáveis" |
| **Avaliar competência geral** | Teoria + prática | "Aplica o framework adequado ao tipo de tarefa" |

### 8.3 Rúbrica-exemplo: Avaliar um prompt construído com RACE

| Critério | Iniciante (1) | Em desenvolvimento (2) | Proficiente (3) | Avançado (4) |
|---|---|---|---|---|
| **Role (R)** | Ausente ou genérico ("você é um especialista") | Presente, mas vago ("você é um designer") | Presente e específico (domínio + senioridade) | Presente, específico e com especialização relevante ao caso |
| **Action (A)** | Ausente ou ambígua ("me ajude") | Presente, mas sem verbo forte | Verbo ativo claro + objeto específico | Verbo ativo + objeto + método/abordagem explicitados |
| **Context (C)** | Ausente | Parcial — faltam dados críticos | Completo — público, situação e restrições | Completo + inclui dados/provas/exemplos que ancoram a IA |
| **Expectation (E)** | Ausente | Apenas formato ("em lista") | Formato + extensão + tom | Formato + extensão + tom + critérios mensuráveis de sucesso |

> **Nota:** Esta rúbrica é **ilustrativa** — derivada do framework RACE verificado em `race.md`. Não há paper acadêmico que a formalize; é aplicação prática de um framework prático.

### 8.4 Rúbrica-exemplo: Avaliar a saída de uma IA generativa

| Critério | Iniciante (1) | Em desenvolvimento (2) | Proficiente (3) | Avançado (4) |
|---|---|---|---|---|
| **Precisão factual** | Contém erros verificáveis/alucinações | Maioria correta, alguns erros | Sem erros óbvios | Fatos checáveis e fontes implícitas confiáveis |
| **Aderência ao prompt** | Ignora ≥2 instruções | Cumpre a maioria, falha em 1 | Cumpre todas as instruções explícitas | Cumpre todas + antecipa implicações |
| **Clareza** | Confusa ou desorganizada | Compreensível com releitura | Clara e bem estruturada | Clara, bem estruturada e envolvente |
| **Formatação** | Não segue formato pedido | Segue parcialmente | Segue formato pedido | Segue formato + usa formatação apropriada ao conteúdo |
| **Tom/Registro** | Inadequado ao público | Adequado em partes | Adequado ao público-alvo | Adequado + consistente do início ao fim |

## 9. Etimologia e história

- O termo **"rubric"** tradicionalmente referia-se a **instruções em uma prova** ou a um **cabeçalho em um documento** (do latim *rubrica*, "vermelho", cor usada para destacar cabeçalhos em manuscritos medievais).
- Na educação moderna, evoluiu para denotar **ferramenta de avaliação vinculada a objetivos de aprendizagem**.
- A transição do uso médico/educacional ocorreu via construção das *"Standardized Developmental Ratings"* em meados dos anos 1970, posteriormente adaptadas para **avaliação de escrita** (*writing assessment*).

---

## 10. Aspectos técnicos — confiabilidade da avaliação

Rúbricas de avaliação **melhoram a consistência da correção** (*scoring consistency*), fornecendo aos educadores uma ferramenta confiável de classificação. A correção é **mais consistente** quando se usa rúbrica, **reduzindo a variação** entre estudantes e entre diferentes professores.

> ⚠️ **Observação:** consistência não implica validade. Uma rúbrica pode ser consistentemente aplicada e ainda avaliar algo diferente do que se pretende. **Alinhamento com objetivos de aprendizagem** é condição necessária para validade.

---

## 11. Como criar rúbricas de desenvolvimento

Roteiro específico para rúbricas de desenvolvimento (Dirlam, 2017):

1. **Localize uma comunidade de praticantes** especialistas no campo, experientes com aprendizes.
2. **Cada praticante trabalha com um entrevistador de desenvolvimento** para criar uma matriz que reflita suas experiências. Várias entrevistas podem ser combinadas em um único conjunto de rúbricas via análise textual manual ou computadorizada.
3. **A comunidade de especialistas avalia desempenhos de aprendizes** e se reúne para comparar classificações e revisar definições quando múltiplas interpretações surgem.
4. **Instrutores de cursos específicos compartilham as rúbricas** com os alunos e identificam os modos-alvo de prática para o curso. Tipicamente, um curso aborda apenas uma fração das dimensões e apenas um modo por dimensão.
5. **As rúbricas são usadas em tempo real** para motivar o desenvolvimento do aluno, geralmente focando em uma dimensão por vez e discutindo oportunidades de avançar ao próximo modo de prática na sucessão.

## 12. Boas práticas resumidas

| Boa prática | Por quê |
|---|---|
| Compartilhe a rúbrica **antes** da entrega | Alinha expectativas, permite autoavaliação |
| Use descritores **observáveis** | Reduz subjetividade na correção |
| Limite a 3-7 critérios | Rúbrica muito longa perde utilidade prática |
| **Teste a rúbrica** em trabalhos-exemplo | Revela descritores ambíguos antes do uso real |
| Atribua **pesos** se dimensões têm importância diferente | Reflete prioridade pedagógica real |
| **Calibre** com outros avaliadores | Garante consistência entre corretores |
| Conecte cada critério a um **objetivo de aprendizagem** | Garante validade da avaliação |
| Use **auto e heteroavaliação** | Reforça aprendizagem e internalização dos critérios |
